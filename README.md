Учебный проект: Python, Selenium, pytest, Page Object Model, Allure, Firefox.

## Результат проверки 17.11.2026

Повторный прогон после исправления замечаний ревьюера в Firefox 160.0:
**11 passed, 1 failed**, 157,73 секунды.
Все FAQ, оба заказа и переход на главную Самоката проходят.
Проверка логотипа Яндекса не проходит: новое окно остаётся на `https://ya.ru/`,

актуальность требования о Дзене.

`requirements-lock.txt` содержит точные версии зависимостей проверенного окружения.

## Исправления по ревью

- Обращения к WebDriver и ожиданиям перенесены в `BasePage`.
  Классы страниц используют унаследованные методы для URL, окон, текста и клавиш.
  Получение скриншотов для Allure также выполняется через `BasePage`.
- В генераторной фикстуре Firefox завершение работы браузера выполняется после
  `yield` без дополнительного `try/finally`.

## Покрытие

- 8 отдельных параметризованных проверок ответов FAQ.
- 2 позитивных заказа: верхняя/нижняя кнопка, разные получатели, станции, сроки и цвета.
- Возврат с формы заказа на главную через логотип Самоката.
- Переход в новое окно через логотип Яндекса с проверкой главной Дзена по условию задания.

## Запуск

Нужны Python 3.10+ и Firefox. Команды выполняются из папки Sprint_6:

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m pytest
```

По умолчанию Firefox работает без видимого окна. Для видимого окна добавьте `--headed`.
Каждый тест использует новый браузер; после теста браузер закрывается.
Selenium Manager подбирает драйвер автоматически, для первого запуска нужен интернет.
Для нестандартного расположения можно задать `FIREFOX_BINARY` и `GECKODRIVER`.

## Allure

Результаты запуска сохраняются в `allure-results`, предыдущие результаты очищаются при новом запуске.
При падении прикладываются скриншот и адрес страницы. Шаги описаны декораторами `allure.step`.

Для Allure 3 (Node.js 22+):

```powershell
npx allure generate allure-results --output allure-report
npx allure open allure-report
```

Для установленного Allure 2 (требует Java):

```powershell
allure generate allure-results --clean -o allure-report
allure open allure-report
```

## Структура

`pages/` — классы страниц; `locators/` — локаторы; `test/` — тесты по функциональности;
`data.py` — ожидаемые ответы и данные заказов; `conftest.py` — Firefox и вложения Allure.

Ожидаемые ответы FAQ фиксированы, а не считываются из приложения во время теста.
Дата доставки рассчитывается как текущая дата + 2 дня. Явные ожидания используются вместо `sleep`.
Данные получателей синтетические, запуск создаёт два заказа на учебном стенде.
